# 위더스 일정비서 설치 설명서

> 체크리스트와 코드 복사 버튼이 있는 단계별 안내 페이지: `apps-script/dist/setup-guide.html`
> 코드를 고친 뒤에는 `node apps-script/build.js` 로 한 파일 버전과 안내 페이지를 다시 만들어요.

손님 문자가 오면 자동으로 일정표와 비교해서, 겹치면 카카오톡으로 알려주는 시스템이에요.
모든 것이 **구글 시트 + 무료 앱**으로 돌아가서 기본 사용료는 **0원**이에요.

```
아빠 폰에 손님 문자 도착
   │  (문자 전달 앱이 자동으로 보냄)
   ▼
구글 Apps Script (무료 서버) ── 일정은 구글 시트에 저장
   │  날짜·시간·작업 읽기 → 일정표와 비교
   ├─▶ 카카오톡 "나와의 채팅"으로 알림  (겹침 / 가능 / 대신 가능한 시간)
   └─▶ 휴대폰 화면: 주간 달력, 답장 문자 만들기, 일정 넣기
```

## 비용

| 항목 | 비용 |
|---|---|
| 구글 시트 + Apps Script (서버) | 0원 |
| 문자 전달 앱 (Incoming SMS to URL forwarder) | 0원 |
| 카카오톡 "나에게 보내기" 알림 | 0원 |
| 문자 읽기: 기본 (규칙 방식) | 0원 |
| 문자 읽기: AI (선택) | 아래 'AI로 읽기' 참고 |

처음에는 AI 없이 써 보고, 날짜를 자주 못 읽을 때만 AI를 켜는 걸 추천해요.

---

## 1. 구글 시트에 코드 넣기 (컴퓨터에서, 약 10분)

1. 아빠 구글 계정(또는 본인 계정)으로 [sheets.new](https://sheets.new) 를 열어 새 시트를 만들어요. 이름은 `위더스 일정`처럼 아무거나 괜찮아요.
2. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 가운데 편집창의 `Code.gs` 내용을 모두 지우고, **`apps-script/dist/위더스일정비서.gs` 파일 전체**를 붙여넣어요.
   (모든 코드가 이 파일 하나에 들어 있어요. 단계별 안내 페이지 `dist/setup-guide.html` 의 **코드 복사** 버튼을 써도 돼요.)
4. 저장(디스크 아이콘)을 누르고, 위쪽 함수 목록에서 **`setup`** 을 고른 뒤 **실행**을 눌러요.
   - 권한 요청 창이 뜨면 계정을 고르고, "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용** 을 누르면 돼요. 내가 만든 코드라서 나오는 정상적인 경고예요.
   - 시트에 `일정`, `문의` 탭이 생기면 성공이에요.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. 톱니바퀴에서 유형 **웹 앱** 을 고르고 아래처럼 정해요.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   (문자 전달 앱이 로그인 없이 보내야 해서 '모든 사용자'로 해요. 대신 주소에 비밀 키가 붙어 있어서 키를 모르는 사람은 못 열어요.)
3. **배포**를 누르고, 함수 목록에서 **`showLinks`** 를 골라 **실행**해요.
4. 아래 **실행 로그**와 시트의 **`안내` 탭**에 주소 3개가 나와요.
   - ① 휴대폰 화면 주소
   - ② 문자 전달 앱에 넣을 주소
   - ③ 카카오 Redirect URI

> ⚠️ 주소의 `key=...` 부분은 비밀번호와 같아요. 다른 사람에게 보내지 마세요.

## 3. 아빠 폰에 화면 추가하기

1. 주소 ①(시트 `안내` 탭 B2 칸)을 카카오톡으로 아빠에게 보내고, 아빠 폰 **크롬**에서 열어요.
2. 크롬 메뉴(⋮) → **홈 화면에 추가** 를 누르면 앱처럼 아이콘이 생겨요.
3. 화면 맨 위에 "Google Apps Script 사용자가 만든 앱" 같은 회색 안내가 보일 수 있는데, 정상이에요.

## 4. 문자 자동 전달 앱 설치 (아빠 폰, 안드로이드)

사용하는 앱: **Incoming SMS to URL forwarder** (무료, 오픈소스)

이 앱은 정책 때문에 **구글 플레이에는 없어요.** 아래 둘 중 한 곳에서 받아요.
- F-Droid: https://f-droid.org/packages/tech.bogomolov.incomingsmsgateway/
- GitHub: https://github.com/bogkonstantin/android_income_sms_gateway_webhook/releases (최신 버전의 `.apk` 파일)

설치할 때 "출처를 알 수 없는 앱" 허용을 물어보면 허용해요. Play 프로텍트 경고가 뜰 수 있는데, 앱 제작자 설명으로는 잘못된 경고예요.

설정 방법:
1. 앱을 열고 문자 수신 권한, 알림 권한을 허용해요.
2. **+** 버튼으로 규칙을 하나 만들어요.
   - **Sender(보낸 사람)**: `*` (모든 번호)
   - **Webhook URL**: 일정비서 화면 맨 아래 **연결 상태 → 전달 앱 주소 복사** 로 복사해서 붙여넣기 (주소 ②와 같아요)
   - **JSON 템플릿**: 기본값 그대로 두기 (`from`, `text` 가 들어 있으면 돼요)
3. 저장하면 끝이에요.

꼭 해 둘 것:
- **배터리 최적화 끄기**: 설정 → 애플리케이션 → 이 앱 → 배터리 → **제한 없음**. 안 하면 폰이 쉬는 동안 전달이 멈출 수 있어요.
- 삼성 메시지의 **채팅+** 나 구글 메시지의 **RCS 채팅**으로 온 메시지는 일반 문자가 아니라서 전달되지 않아요. 손님이 같은 기능을 쓰는 경우가 많으면 해당 기능을 꺼 두세요.

어떤 문자가 처리되나요?
- 은행·카드·택배·인증번호·광고 문자(`[Web발신]`, `(광고)` 등)는 자동으로 무시해요.
- "청소, 에어컨, 예약, 입주" 같은 말이 있거나, 날짜와 시간이 함께 있으면 문의로 저장해요.
- 아빠 폰의 다른 문자는 시트에 저장되지 않아요.

**테스트**: 다른 폰에서 아빠 폰으로 `내일 오후 3시 벽걸이 에어컨 2대 청소 가능할까요?` 라고 보내 보세요. 1분 안에 화면의 **문의** 탭에 떠야 해요 (화면에서 **새로고침**). 화면 맨 아래 연결 상태가 **연결됨**으로 바뀌어요.

## 5. 카카오톡 알림 켜기 (선택, 무료)

카카오톡 '나와의 채팅'으로 이런 알림이 와요.

```
[일정 겹침] 새 문의
11/27(금) 오전 10시 · 벽걸이2
김미영 010-2345-6789
겹침: 09:30 박상철
가능: 11/27(금) 오후 12시 / 11/28(토) 오전 10시
[일정 확인] ← 누르면 휴대폰 화면이 열려요
```

설정 방법 (컴퓨터에서, 카카오 개발자 사이트 메뉴 이름은 조금 바뀔 수 있어요):
1. [developers.kakao.com](https://developers.kakao.com) 에 **아빠 카카오 계정**으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** (이름: `위더스 일정비서`).
2. **앱 키**에서 **REST API 키**를 복사해요.
3. **카카오 로그인** 을 **사용(ON)** 으로 바꾸고, **Redirect URI** 에 주소 ③을 등록해요.
4. **동의항목**에서 **카카오톡 메시지 전송(talk_message)** 을 **사용**으로 바꿔요.
5. **플랫폼 → Web** 의 사이트 도메인에 `https://script.google.com` 을 등록해요 (알림의 버튼 링크가 열리도록).
6. (보안 메뉴에서 **Client Secret** 을 켰다면, 그 코드도 복사해 두세요.)
7. Apps Script **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - `KAKAO_REST_KEY` = REST API 키
   - (Client Secret을 켰다면) `KAKAO_CLIENT_SECRET` = 코드
8. 아빠 폰 화면 맨 아래 **알림 · AI 설정** 에서 **카카오톡 연결하기** → 아빠 카카오로 로그인 → 동의.
9. 카카오톡 '나와의 채팅'에 **[연결 완료]** 메시지가 오면 끝이에요.

연결은 매일 새벽 자동으로 갱신돼서 계속 유지돼요. 혹시 알림이 멈추면 8번만 다시 하면 돼요.

## 6. AI로 읽기 (선택, 유료)

기본 방식(규칙)은 "11월 28일", "내일", "다음주 수요일", "오후 2시", "벽걸이 2대" 같은 흔한 표현을 읽어요.
말투가 특이한 문자를 자주 놓치면 AI를 켤 수 있어요. AI가 실패하면 자동으로 기본 방식으로 돌아가요.

1. [platform.claude.com](https://platform.claude.com) 에서 가입하고 API 키를 만들어요. 사용료는 미리 충전해서 쓰는 방식이에요.
2. Apps Script **스크립트 속성**에 추가해요.
   - `ANTHROPIC_API_KEY` = API 키
   - `AI_MODEL` = 사용할 모델 (비워두면 `claude-opus-5-5`)
3. 함수 목록에서 **`testAI`** 를 실행해서 로그에 결과가 나오면 성공이에요.

대략적인 비용 (문의 문자 한 통 기준, 1달러 = 1,400원으로 계산한 추정치):

| `AI_MODEL` | 문자 1통 | 하루 10통 × 30일 |
|---|---|---|
| `claude-opus-5-5` (기본, 가장 똑똑함) | 약 17원 | 약 5,000원 |
| `claude-haiku-5-5` (가장 저렴함) | 1원 미만 | 약 150원 |

문자 길이에 따라 조금씩 달라요. 은행·광고 문자는 AI에 보내지 않아서 비용이 들지 않아요.

## 작업 기준 바꾸기

`Code.gs` 맨 위 `CONFIG` 에서 고칠 수 있어요.

| 항목 | 지금 값 | 뜻 |
|---|---|---|
| `open` / `close` | 8시 / 19시 | 작업 가능한 시간 |
| `buffer` | 30 | 작업 사이 이동시간(분) |
| `unit` | 벽걸이 60, 스탠드 90, 투인원 150, 시스템 120 | 1대당 작업 시간(분) |
| `fullStart` / `fullDur` | 8시 30분 / 9시간 | 입주·이사청소 |
| `closedDays` | `[0]` | 휴무 요일 (0=일요일, 6=토요일) |

## 코드를 고친 뒤에는

Apps Script는 저장만 해서는 화면에 반영되지 않아요.
**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 해요. 이렇게 하면 주소는 그대로 유지돼요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 문자가 화면에 안 떠요 | 전달 앱의 로그에 오류가 있는지, 배터리 최적화가 꺼져 있는지, Webhook 주소가 ②와 같은지 |
| 문의 문자인데 무시됐어요 | 화면의 '직접 넣기'에 붙여넣으면 바로 확인할 수 있어요. 자주 그러면 AI를 켜세요 |
| 카카오 알림이 안 와요 | 화면 아래 **테스트 알림 보내기**. 안 되면 **카카오톡 연결하기**를 다시 |
| "주소가 올바르지 않아요" | `?key=...` 가 붙은 주소 ①로 열었는지 |
| 키가 다른 사람에게 알려졌어요 | 스크립트 속성의 `SECRET` 값을 지우고 `setup` → `showLinks` 를 다시 실행한 뒤, 새 주소로 전달 앱과 홈 화면을 바꾸세요 |
