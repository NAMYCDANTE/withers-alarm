카카오톡으로 알림 받기

여기까지만 해도 문의는 자동으로 쌓여요. 다만 아빠가 화면을 열어야 볼 수 있어요. 이 단계를 하면 새 문의가 올 때마다 카톡 '나와의 채팅'으로 겹침 여부와 대신 가능한 시간이 바로 와요. 무료예요.

  1. developers.kakao.com 에 아빠 카카오 계정으로 로그인해요. (개발자 등록 약관 동의가 나오면 동의)
  2. 내 애플리케이션 → 애플리케이션 추가하기 → 앱 이름 위더스 일정비서, 회사명 위더스환경 → 저장.
  3. 만든 앱에 들어가 앱 키 의 REST API 키를 복사해 메모장에 둬요.
  4. 카카오 로그인 메뉴에서 활성화 설정을 ON 으로 바꿔요.
  5. 같은 곳(또는 REST API 키 설정)의 Redirect URI 에 시트 안내 탭의 B4 칸(③ 주소, …/exec 로 끝남)을 등록해요.
  6. 동의항목 에서 카카오톡 메시지 전송 을 설정 → 선택 동의 로 저장해요.
  7. 플랫폼 → Web 플랫폼 등록 에 https://script.google.com 을 넣어요. (알림의 버튼이 열리게)
카카오 개발자 사이트는 메뉴 위치가 가끔 바뀌어요. 이름이 조금 달라도 '카카오 로그인', 'Redirect URI', '동의항목', '플랫폼'을 찾으면 돼요.
  1. Apps Script 왼쪽 톱니바퀴 프로젝트 설정 → 맨 아래 스크립트 속성 추가.
  2. 속성 KAKAO_REST_KEY, 값에 11단계의 REST API 키 → 스크립트 속성 저장.
카카오에서 Client Secret 을 '사용함'으로 켰다면, 그 코드도 속성 KAKAO_CLIENT_SECRET 으로 넣어요. 따로 켜지 않았다면 넣지 않아도 돼요.
  1. 일정비서 화면을 열고 새로고침.
  2. 맨 아래 카카오톡 연결하기 → 카카오로 로그인 → 아빠 카카오 계정으로 동의.
  3. 카카오톡 나와의 채팅에 [연결 완료] 메시지가 오면 끝이에요.
카카오 연결은 매일 새벽 자동으로 갱신돼요. 혹시 알림이 끊기면 이 단계만 다시 하면 돼요.

문제가 생기면

테스트 문자가 화면에 안 떠요

① 전달 앱 규칙의 Webhook URL이 화면의 '전달 앱 주소'와 똑같은지 확인해요. ② 전달 앱이 문자 권한을 가지고 있는지 확인해요. ③ 보내는 폰에서 '채팅+'가 아닌 일반 문자로 보내요. ④ 전달 앱 설정에 'chunked' 관련 옵션이 있으면 바꿔서 다시 보내 봐요.

"주소가 올바르지 않아요" 라고 떠요

?key=… 까지 포함된 주소 전체를 복사했는지 확인해요. 시트 안내 탭의 B2 칸을 그대로 쓰면 돼요.

문의 문자인데 목록에 없어요

은행·광고처럼 보이는 문자는 자동으로 건너뛰어요. 화면의 '직접 넣기' 칸에 붙여넣으면 바로 확인할 수 있어요. 전화로 받은 예약도 이 칸에 적으면 돼요.

날짜나 시간을 잘못 읽었어요

결과 화면에서 날짜, 시간, 소요시간을 직접 고치거나 달력의 빈 칸을 누르면 다시 확인해요. 자주 틀리는 문자 예시를 모아 두면 규칙을 더 똑똑하게 고칠 수 있어요.

Apps Script 코드를 바꿨는데 화면이 그대로예요

저장만으로는 반영되지 않아요. 배포 → 배포 관리 → 연필(수정) → 버전 새 버전 → 배포 를 해야 해요. 주소는 그대로 유지돼요.

비밀 주소가 다른 사람에게 알려졌어요

프로젝트 설정 → 스크립트 속성에서 SECRET 을 삭제하고, setup → showLinks 를 다시 실행해요. 새 주소로 아빠 폰 홈 화면과 전달 앱의 주소를 바꿔요.
